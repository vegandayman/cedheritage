Heritage Format Checker: Documentation and Instructions

← Back to Checker

Overview

The Heritage Format Checker is a client-side application designed to verify card and deck legality for the Heritage format. It relies on a pre-compiled JSON database of legal cards, ensuring fast, zero-backend performance.

Instructions: Searching the Database

  1. Initialize the App: Click the "LOAD DATABASE" button upon arriving at the page to fetch the latest legal card pool.
  2. Name Search: Enter keywords in the "Name keyword" field.
  3. Type Filtering: Begin typing in the "Add card type/subtype" field. Select from the dropdown suggestions to add specific types as tags. You can add multiple tags to narrow down results.
  4. Oracle Text: Enter rules text keywords (e.g., "proliferate") into the Rules text input field to find specific mechanics.
  5. View Results: Click "Search Heritage". The application will return up to 50 matching cards. Clicking any card image will open its corresponding Scryfall entry in a new tab. Once a search is run, there is an "open these results in Scryfall" button if you want to explore your specific search query beyond the displayed 50 limit.

Instructions: Decklist Legality Checker

  1. Input Your Deck: Either click "Choose File" to upload a .txt decklist, or paste your list directly into the provided text area.
  2. Formatting Requirements: Standard decklist formatting is accepted. The system automatically strips card quantities and set codes.
  3. Ignored Elements: The checker will skip over lines starting with "Sideboard" or "Commander". Basic lands (Plains, Island, Swamp, Mountain, Forest, and their snow-covered variants) are bypassed automatically.
  4. Review the Report: Click "Check Legality". The tool provides a summary of total cards checked, with counts for both legal and illegal entries.
  5. Identify Illegal Cards: Illegal cards are highlighted in red and include a link to search for the card on Scryfall for further investigation.
  6. Flavor Name Display: If a valid card was submitted under its Universes Beyond flavor name, the report will display both the submitted name and the base premier name in brackets.

Feature List

  • Offline Database Loading: Loads a static, pre-compiled JSON file (heritage_cards.json) directly into the browser.
  • Comprehensive Database: The database exclusively includes Commander-legal cards from core and expansion sets, explicitly filtering out Universes Beyond cards.
  • Promotional Reskin Support: Universes Beyond cards that are purely promotional reskins of legal premier cards (flavor names) are automatically recognized as legal.
  • Advanced Card Search: Filter the legal card pool by Name, Oracle text, and Type/Subtype.
  • Interactive Type Tags: An auto-completing typeahead input allows users to stack multiple card types or subtypes (e.g., "Goblin", "Instant") for precise filtering.
  • Decklist Verification: Check entire decklists for legality by pasting text or uploading a standard .txt file.
